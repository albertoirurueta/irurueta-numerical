= Measurement Noise Covariance Estimation
:description: Incremental estimation of sample mean and covariance for measuring Kalman filter measurement \
noise, implemented by MeasurementNoiseCovarianceEstimator.
:keywords: measurement noise covariance, Kalman filter, running covariance, incremental mean and covariance, \
MeasurementNoiseCovarianceEstimator, sensor noise estimation, signal processing, sample covariance
:stem: latexmath

NOTE: This documentation was generated with the assistance of AI. Please report any inaccuracies.

A xref:algorithms/kalman-filter.adoc[Kalman filter] needs a measurement noise covariance matrix stem:[R] to
weigh how much it should trust each incoming measurement. Rather than guessing stem:[R], it can be measured
directly: hold the system's true state constant (e.g. keep a sensor motionless) and record repeated samples —
any variation left in the data, once its mean is removed, is pure measurement noise. This class implements that
idea as a running (incremental) estimate of the sample mean and covariance, updated one sample at a time rather
than requiring the whole dataset up front. It is implemented as `MeasurementNoiseCovarianceEstimator` in the
`com.irurueta.numerical.signal.processing` package; the general approach of updating a mean and covariance
incrementally, one sample at a time, is described in
xref:reference.adoc#wikipedia-variance[Wikipedia contributors, Algorithms for calculating variance].

== Running mean and covariance

For each new sample stem:[\mathbf{x}_{N+1}] (an `mp`-dimensional vector, with `mp` the number of measurement
dimensions), the sample count, average, and covariance are all updated in place. The average is updated as:

[stem]
++++
\mathbf{\bar{x}}_{N+1} = \frac{N \cdot \mathbf{\bar{x}}_N + \mathbf{x}_{N+1}}{N + 1}
++++

The covariance update folds the outer product of the new sample's deviation from the *previous* mean and from the
*updated* mean into the running covariance, rescaled for the new sample count:

[stem]
++++
\boldsymbol{\Sigma}_{N+1} = \frac{N \cdot \boldsymbol{\Sigma}_N + \left(\mathbf{x}_{N+1} - \mathbf{\bar{x}}_N\right)\left(\mathbf{x}_{N+1} - \mathbf{\bar{x}}_{N+1}\right)^T}{N + 1}
++++

Since stem:[\mathbf{x}_{N+1} - \mathbf{\bar{x}}_{N+1} = \frac{N}{N+1}\boldsymbol{\delta}] with
stem:[\boldsymbol{\delta} = \mathbf{x}_{N+1} - \mathbf{\bar{x}}_N], the outer product above is equivalent to
stem:[\boldsymbol{\delta}\boldsymbol{\delta}^T \cdot \frac{N}{N+1}]. This is the Welford-style recursive
relationship described in xref:reference.adoc#wikipedia-variance[Wikipedia contributors, Algorithms for calculating variance],
and the result equals the batch population covariance of all samples seen so far at every step.

This is the relationship implemented by `update(double[])`: `sampleNoMean` is first computed as the new sample minus
the pre-update `sampleAverage`, `sampleAverage` is then updated, the outer product of `sampleNoMean` is scaled by
`N / (N + 1)`, and `measurementNoiseCov` is rescaled by `sampleCount`, has that term added, and is rescaled again by
`1 / nextCount`.

[mermaid]
....
flowchart TD
    A["New sample x arrives; N = current sampleCount"] --> B["delta = x - average"]
    B --> C["singleCov = delta * delta^T"]
    C --> D["singleCov = singleCov * N / (N + 1)"]
    D --> E["average = (average * N + x) / (N + 1)"]
    E --> F["cov = (cov * N + singleCov) / (N + 1)"]
    F --> G["sampleCount = N + 1"]
    G --> H["Return updated covariance"]
....

== Library implementation

`MeasurementNoiseCovarianceEstimator(int measureParams)` allocates the running state for a system with
`measureParams` measurement dimensions (`mp`).

* `update(double[] sample)` — folds one new sample into the running mean and covariance, and returns the
  updated covariance matrix. `sample` must have length `mp`.
* `getMeasurementNoiseCov()` — the current running covariance estimate (`mp`×`mp`), suitable for passing
  directly to `KalmanFilter.setMeasurementNoiseCov(Matrix)`.
* `getSampleAverage()` — the current running mean (length `mp`); mainly useful as a bias/offset check, since a
  properly zeroed sensor should show an average close to zero.
* `getSampleCount()` — the number of samples folded in so far.

TIP: Collect samples with the sensor in a fixed, representative state (e.g. stationary, at the operating
temperature the sensor will actually run at) before starting a
xref:algorithms/kalman-filter.adoc[`KalmanFilter`] — noise characteristics measured under different conditions
than the filter will actually run under can under- or over-state how much the filter should trust each
measurement.

== Example

Estimating the noise covariance of a 3-axis accelerometer held motionless, then using it to configure a Kalman
filter's measurement noise:

[source,java]
----
final var noiseEstimator = new MeasurementNoiseCovarianceEstimator(3);
for (final var sample : stationarySamples) { // stationarySamples: List<double[]> of length-3 readings
    noiseEstimator.update(sample);
}

final var measurementNoiseCov = noiseEstimator.getMeasurementNoiseCov();

final var filter = new KalmanFilter(6, 3); // e.g. position + velocity per axis, measuring acceleration
filter.setMeasurementNoiseCov(measurementNoiseCov);
----
