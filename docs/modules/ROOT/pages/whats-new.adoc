= What's New

== 1.7.1

* 🐛 Fixed the mid-point Simpson integrators (plain, infinity, lower/upper square-root mid-point, and their matrix
  variants): they now use the extrapolation that matches the tripling step of the mid-point rules, so smooth
  integrands converge with far fewer evaluations. The number of stages is capped at 14, so integrands that need
  more now throw `IntegrationException` sooner.
* 🐛 Fixed a possible integer overflow in `BaseInterpolator`'s binary search on very large index ranges.
* 📚 Documented the single-threaded contract of robust estimators and their listeners.
* ♻️ Cleaned up Checkstyle, PMD and SpotBugs findings, with no API change.

== 1.7.0

* ✨ Added configurable `relativeStep` and `minStep` to `JacobianEstimator`, `GradientEstimator`,
  `DerivativeEstimator` and their symmetric and Savitzky-Golay variants, improving accuracy for small non-zero
  parameters. Defaults keep the previous behavior.
* 📚 Added a documentation page on numerical derivatives, gradients and Jacobians.

== 1.6.1

* 🐛 Fixed a bias in `MeasurementNoiseCovarianceEstimator`: the running covariance under-weighted each new sample
  and now exactly matches the batch population covariance after every update.
* ♻️ Raised the minimum Java version from 17 to 21.
* ⬆️ Updated `irurueta-algebra`, `irurueta-statistics` and `irurueta-sorting` to 1.4.1.
* 📚 Rewrote the measurement noise covariance documentation and added diagrams and bibliography links to the
  algorithm pages.

== 1.6.0

* 📚 Added the Antora documentation site (this site), including a full algorithm catalog with one page per
  algorithm, an architecture overview, and installation instructions.
* ✨ Added Claude Code skills to automate common repository workflows (release management, documentation
  generation, code review, and more).

No public API or behavior changes in this release.
